# Como contribuir

Obrigado pelo interesse em melhorar a tradução.

## Relatar erros

Use a aba **Issues** e descreva onde o texto aparece. Se possível, anexe uma captura de tela que não revele dados pessoais.

## Sugerir uma tradução

Informe o texto atual, a sugestão e o contexto da cena. Sugestões podem ser ajustadas para manter consistência com o restante do jogo.

## Arquivos do jogo

Não envie executáveis, DLLs, pacotes Unity ou outros arquivos originais completos do jogo. Contribuições devem conter somente material necessário ao patch e produzido para este projeto.
